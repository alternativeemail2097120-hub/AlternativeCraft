                  How to play

                  • Type your answer as COORDINATE + NUMBER, e.g. A5 7 puts a 7 in Row A, Column 5.
                  • Rows are letters A-I (top to bottom); columns are numbers 1-9 (left to right). No punctuation needed.
                  • Each correct guess earns 1 point. There is no time limit - the clock just shows how long the puzzle takes.
                  • The puzzle: a 9×9 grid in nine 3×3 boxes. Fill every empty cell with 1-9 so each row, column and box has no repeats. Pre-filled "givens" are clues and can't be changed.
                  • 💡 Scan a row, column or box for the digit it is missing, then find the only cell it can legally go in.
                  • Live = real TikTok chat. Test = simulated chat. Offline = just you, type answers directly.
