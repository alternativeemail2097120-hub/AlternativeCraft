                    How to play

                    • Type two card numbers in chat, e.g. 1 5 (a comma works too: 1, 5).
                    • Both cards flip over. If the pictures match, they stay open. If not, they flip back after a moment - remember where they were.
                    • Each pair you find earns 1 point. Match pairs back-to-back for a combo streak - each one in a row is worth more, up to +4 total. A wrong guess resets your streak.
                    • Each picture is hidden on exactly two cards. The game is won when every pair has been found. There is no time limit.
                    • 👁️ Peek shows every card for a moment (host tool, no points).
                    • Live = real TikTok chat. Test = simulated chat. Offline = you (or teams) tap two cards or type their numbers.
