          How to play

          • Make words using the seven letters on the flower. Every word must include the center letter and be at least 4 letters long.
          • The empty boxes show how many secret words of each length are hidden. Fill every box to finish the round.
          • Type a word in chat. A secret word earns full points; any other real word is a bonus word for half points.
          • Words that use all seven letters are pangrams - the star words!
          • Stuck? Use Hint in the host controls to reveal a first letter and length.
          • Live = real TikTok chat, Test = simulated viewers, Offline = the host types.
